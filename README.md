# ji-hun-git.github.io

Personal portfolio of Jihun Chae: human-centered AI research, product strategy,
testable systems, and evidence from real-world evaluation.

## Site structure

- `index.html` — portfolio, selected systems, research, recognition, and credentials.
- `styles.css` — the complete portfolio visual system and responsive layout.
- `app.js` — restrained reveal motion and active-section navigation.
- `laboratory.html` + `lab/` — interactive simulation catalogue.
- `assets/profile/` — profile imagery.
- `assets/og-jihun-chae.png` — social-preview image.
- `assets/logos/` — institutional marks used to identify project context.

The site is static and is served directly by GitHub Pages. It has no build step.
